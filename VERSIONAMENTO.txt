REGRA PARA AS PRÓXIMAS VERSÕES
==============================

1. Antes do commit, adicionar a versão e uma descrição curta neste arquivo.
2. Criar o commit da versão.
3. Copiar o hash gerado pelo Git para a entrada correspondente.
4. Registrar a atualização do hash em um pequeno commit de versionamento.

O hash de um commit não pode ser gravado dentro do próprio commit antes de ele
existir. Por isso, a versão entra primeiro como PENDENTE e recebe o hash logo
após a criação do commit principal.
